# raw/ — source material

Drop source documents here: meeting transcripts, email/Slack exports, articles, PDFs, brain dumps, call notes.

**Rules:**

- These files are **immutable**. Read them; never edit them. They're the evidence trail.
- Nothing here is the "answer" — the interpreted knowledge lives in `wiki/`. To turn a raw file into knowledge, run **ingest** (see the brain's `CLAUDE.md`, or `/ingest`).
- **Don't commit secrets.** No `.env`, no credential dumps.

Once a source is ingested, it gets a summary page in `wiki/` (named `source-YYYY-MM-DD-title.md`) and a line in `log.md`.
